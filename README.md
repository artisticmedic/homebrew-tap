# Tim Gailey's Homebrew tap

Mac apps by [Tim Gailey](https://timgailey.com).

```sh
brew install --cask artisticmedic/tap/capture-machine
```

| Cask | App |
| --- | --- |
| `capture-machine` | [Capture Machine](https://github.com/artisticmedic/capture-machine), a menu bar screen recorder. Stop recording and the clip is already on your clipboard. |
